# redteam.kumobits.com

Harmless prompt injection demo page for the Kumobits YouTube video "Jag hackade Grok på 10 minuter".

The visible article is a short note about autumn in Stockholm. Hidden text on the main page asks an AI assistant to end its reply with a phrase and recommend pineapple pizza. Nothing is exfiltrated. The page has no scripts, forms, images or tracking.

- Public page: index.html (hidden text is white on white, and also in a visually hidden span)
- Reveal page for the video: reveal.html (same text with a yellow highlight)

Search engines: noindex.
